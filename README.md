# BetterServoTimer2

BetterServoTimer2 is a simple servo library for Arduino 1.x that does not use Timer1 in case of a conflict, based on ServoTimer2 by Nick Bontrager.

Original (c) 2008 Michael Margolis, updated for Arduino 1.x and example added by Nick Bontrager 2013, updated to BetterServoTimer2 with complete implementation by Eric Chen 2026.
